# Calc3D product context

Register: product. Calc3D is an owner-scoped, Spanish-language 3D-print quotation and test-inventory tool using CLP. Its existing Settings and Calculator interfaces are the visual reference; this feature extends them rather than redesigning or rebranding them.

## Confirmed workflow

An authorized account maintains printer settings, spool presentations and quotations. A separate brand maintainer lets the owner explicitly save a brand name and representative color. A spool profile selects a brand by stable identity and separately stores a readable filament color name with an optional representative sample. Both pickers distinguish the brand marker from the filament sample; unknown or unrepresentable colors do not get an invented sample. Purchases and saved quotations retain historical snapshots and prices.

## Boundaries

Preserve existing Spanish functional copy, familiar controls, owner isolation, explicit saves, current pricing and the approved visual system. No new audience, personality, marketing theme, fonts or dependencies have been specified. DESIGN.md is not present; the existing UI and styles remain the design reference.
