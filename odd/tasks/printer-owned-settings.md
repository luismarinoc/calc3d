Objective: configure fixed printer costs once and keep each quotation linked to the printer and parameters actually used. Branch: feat/print3d-management.
Delivery: local feature-branch work units (auto-chain / feature-branch-chain); no publication. Runners: Node test runner and isolated Playwright. Risk: item 4 (settings persistence and stale-tab writes).
