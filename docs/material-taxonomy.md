# Material families

The consultation material filter uses `canonicalMaterial` from `src/domain/materials.mjs`. It classifies observed material labels as **ABS, ASA, HIPS, PA, PA6, PA12, PC, PCL, PEBA, PET, PETG, PLA, PVA, TPE, TPU**. Case variants, chemical expansions, finishes, fillers, hardness and speed grades collapse to their evidenced base family (for example, `Petg`, `PETG (Polietileno Tereftalato Glicolado)` → `PETG`; `PLA Mate`, `PLA+`, `PLA Lite` → `PLA`). Nylon without a specified grade maps to `PA`; explicitly marked PA6 and PA12 remain separate. PET and PETG, ABS and ASA, TPU and TPE are distinct. Unknown labels remain visible as normalized free text, not guessed polymers.

This is **not** a product-name rewrite or an edit-form constraint. Supplier names, source evidence, prices, colors, archives and historical quote snapshots remain unchanged. The versioned private operator under `.cache/odd/spool-color-materials/operator-v2/` prepares guarded material-only updates for existing owner rows; it is not run by the application and requires separate proof and parent-only native execution. A changed profile increments revision and updates `updated_at`; an unchanged profile is untouched. Pending references change only their material field. No new schema, RPC, security policy or material-to-price mapping is introduced.
